# Task implemented

- Implemented `skeleton++`: a three-stage script (clang++ to cir-opt to driver) that takes a whole C++ program and either emits a standalone executable (CPU-only, with the unit IR embedded) or JITs it, placing each operator on CPU or GPU at run time.
- Implemented `mlir-skeleton-driver`: the run-time entry point. It takes the module the front end produces (host and outlined operator units still in one module) or an emitted artifact, splits the units into per-operator modules itself, rewrites every operator call into a `skeleton_rt_resolve` plus an indirect call, and JITs and runs the host in its own process. Each resolve picks a device from the unit's declared preference and the (cached) device probe, falls back to the CPU on unavailability or insufficient device memory, and on a miss calls back into the driver, which compiles that unit's skeleton IR for the chosen device. With `--emit` it instead links a standalone CPU-only executable with the IR embedded.

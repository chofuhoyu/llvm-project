# Task implemented

- Implemented `skeleton++`: a three-stage script (clang++ to cir-opt to driver)
  that takes a whole C++ program and either emits a standalone executable
  (CPU-only, with the unit IR embedded) or JITs it, placing each operator on
  CPU or GPU at run time.
- Implemented `mlir-skeleton-driver`: the runtime driver. It accepts the split
  MLIR module, resolves every operator call at run time from the annotation's
  preference and the device probe, compiles a unit on a cache miss, and runs
  the program in-process.

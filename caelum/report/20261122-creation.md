# 算子识别与算子调度的创新点

> 中期审核材料。仅整理算子识别与算子调度两部分，共四条；每条一段，二百字以内。

## 一、算子识别

1. **提出以源码注解和参数类型为语义来源的算子边界构造方法。** 宿主函数经注解标识并保留原 C++ 签名，算子调用被切分为独立单元，普通调用方无需改写；数据参数以数组引用、运行时视图或运行时缓冲表达，形状与长度的来源由参数类型确定，不再按算子语义构造。算子识别因此转化为对显式书写的翻译，切分结果与用户意图一一对应。

2. **设计并实现一条可验证、对不确定情形显式报错的算子识别与翻译链。** 纯函数引用经类型转换后沿支配的存取链解析到符号，数据参数溯源至宿主入口；纯函数体按白名单翻译为标量算术，遇到控制流、逃逸分配或副作用即给出带定位的诊断并中止，仅在来源唯一时改写。该策略把无法判定的情形转化为编译期错误，避免不完整的模式匹配产生语义错误的中间表示。

## 二、算子调度

3. **提出 CPU 实现与可重编译中间表示的产物模型，将调度决策推迟到运行期。** 编译期不生成异构代码，产物由宿主、各算子的 CPU 实现、内嵌 Skeleton IR 与运行时组成；运行期入口逐算子解析，缓存未命中时从该单元 IR 重新生成目标代码，异构代码的唯一来源是运行期重编译。同一算子在进程内可随设备状态变化重新选择，切回原设备时复用已有实现。

4. **实现以偏好为软约束、以运行期设备状态为判据的逐算子调度与回退机制。** 每次解析按偏好与 CPU 组成候选序列，先探测设备可用性，并在可取得显存读数时校验容量；偏好设备不满足条件则回退 CPU，缺少实现则回调入口即时编译，均不可行时显式终止。探测结果按设备缓存并带刷新间隔，逐算子解析保持常数开销；决策日志记录偏好、探测结果、实际选择与原因，使回退行为可复核。
